Step-by-step session

Work from top to bottom. Each step unlocks the next. If something fails, read the Device line above and the yellow/red alert — then see host prerequisites (libimobiledevice, macFUSE, ifuse).

  1. 1

    Connect the iPhone

    • Use a direct USB cable to the Mac (avoid hubs when troubleshooting).
    • Unlock the phone. If you see Trust This Computer?, tap Trust and enter your passcode.
    • Leave the phone unlocked on the Home Screen while you check detection.
  2. 2

    Mount iPhone storage

    This exposes your photo library to this app (same idea as Finder’s iPhone mount). Mounting can take a few seconds the first time.

  3. 3

    Find duplicate photos optional

    Runs in the background. You can skip this step if you only want document-style cleanup (step 5). If a scan is already running, use Cancel.

  4. 4

    Review duplicates & delete extras

    After the scan finishes, pick one keeper image per group in the section below, then use Delete non-kept duplicates when you are sure.

  5. 5

    Document-style photos optional

    Separate workflow for tagged receipts/scans. Preview first, then remove — copies go to a Mac holding folder so you can undo while still mounted.

  6. 6

    Unmount & disconnect

    Before unplugging USB: close any Finder windows showing the iPhone volume, then unmount here. That flushes the session and clears the document holding area.

    After bulk deletes, iOS may show ghost thumbnails until the phone re-indexes — a restart often fixes this.

Duplicate review

Auto best ranks by sharpness, resolution, file size, then EXIF/mtime time (newer wins ties). Optional face/eye assist (see duplicates.auto_best.face_eye in YAML) is approximate and can mis-rank closed eyes or profile shots; install requirements-mediapipe.txt for that path. Your keep mode choice is saved under data/ui_state.json (ignored by git) when you change it here.

Document-style photos

Matches Apple user tags on the file (Finder-style tags containing “Document”), path or filename hints such as “receipt” or “scan”, and optionally a lightweight “white paper with dark ink” screen. Files are copied to a Mac-only holding folder under your configured data_dir, then removed from the phone so you can undo while still mounted. Unmount clears that holding folder and wipes the thumbnail cache so the session ends clean; treat that as making removals final.
