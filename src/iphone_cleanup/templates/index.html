Step-by-step session

Follow the highlighted step. If something fails, check Device above and the alert banner, then host prerequisites.

  1. 1

    Connect the iPhone

    • Use a direct USB cable to the Mac (avoid hubs when troubleshooting).
    • Unlock the phone. If you see Trust This Computer?, tap Trust and enter your passcode.
    • Leave the phone unlocked on the Home Screen while you check detection.
  2. 2

    Mount iPhone storage

    This exposes your photo library to this app (same idea as Finder’s iPhone mount). Mounting can take a few seconds the first time.

  3. 3

    Find duplicate / similar photos optional

    Exact finds same-size near-identical files. Fuzzy roll groups visually similar shots that appear next to each other in capture-time order (same-subject bursts). Cancel stops quickly; you can run either scan after the other when idle.

  4. 4

    Review duplicates & delete extras

    Tap thumbnails in the panel to toggle keep (blue ring + checkmark). You can keep several files per group; if every file in a group is marked keep, nothing is deleted there. Fuzzy bursts default to keeping images with the most detected eyes when MediaPipe is installed (see optional requirements). Tap this card to scroll to the duplicate summary.

    Scroll to duplicate summary ↓
  5. 5

    Document-style photos optional

    Receipts / scans: copies go to this Mac first so you can undo until you unmount. Tap this card to scroll to the controls.

    Scroll to document cleanup ↓
  6. 6

    Unmount & disconnect

    Before unplugging USB: close any Finder windows showing the iPhone volume, then unmount here. That flushes the session and clears the document holding area.

    Unmount is always available while the phone is mounted — including during an exact or fuzzy scan (it signals cancel) or during a duplicate delete. When unmount succeeds, it clears the document holding folder on this Mac; only unmount when you are done with undo / finalize.

Duplicate review

Long duplicate lists open in a scrollable panel so steps 5–6 stay one short scroll away.

Duplicate review

Keeper choice:

Manual: tap photos to toggle keep (multiple allowed). Use Keep all in group beside each heading to mark every file in that set at once, then tap any tile to remove keep from individual photos. Auto best re-ranks keepers (exact: sharpness/size/recency + optional face/eye; fuzzy: most approximate “eye” count via MediaPipe when available). Delete only removes files you did not mark keep. If every file in a group is kept, that group contributes nothing to delete.

Document-style photos

Matches Document user tags, path/filename hints (e.g. receipt, scan), or an optional white-paper heuristic. Files are copied to this Mac, then removed from the phone — Undo works until you unmount (unmount clears the holding folder and ends the session).
