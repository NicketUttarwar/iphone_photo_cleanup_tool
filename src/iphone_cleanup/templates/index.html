    Unmount & disconnect
    
            
    
              Before unplugging USB: close any Finder windows showing the iPhone volume, then unmount here. That flushes the session and clears the document holding area.
            
    
            
    
              Unmount is always available while the phone is mounted — including during a scan (it signals cancel) or during a delete. When unmount succeeds, it clears the document holding folder on this Mac; only unmount when you are done with undo / finalize.

      Separate workflow for byte-identical / same-size near-duplicate files. On large libraries (10k–100k+ photos) the first exact scan walks the full roll once; review loads sets in pages with every photo in each set shown at full frame (scroll horizontally within a set).
