Host prerequisites

Install these on the Mac before relying on mount/scan/delete.

Checklist

  1. macFUSE — required for FUSE filesystems on macOS (ifuse depends on it).
  2. libimobiledevice — provides ideviceinfo and idevice_id for USB trust and device metadata.
  3. ifuse — mounts the iPhone media tree into the path configured as paths.mount_point in YAML.
  4. usbmuxd — usually installed with libimobiledevice; must be running for USB.

If binaries are missing, run ./scripts/run.sh and read the stderr hints from scripts/check_host_prerequisites.sh, or see docs/workflows/first-run-setup.md.
